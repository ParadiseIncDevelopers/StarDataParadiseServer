Önizleme kaynak etiketleri Server için `v0.5.0-preview.1`, CLI için `v0.3.0-preview.1`, klasik Workbench için `v0.2.0-preview.1` ve Java SDK için `v0.3.0-preview.1` olarak ayrıldı. Server, CLI ve Workbench üst kaynak değişiklikleri ilgili ürün deposunda sabit commit’e uygulanan yamalarla tutulur. Workbench önizlemesi test edilen klasik 8.0.43 paketine dayanır.

Durum: IN_PROGRESS. Windows x64 yerel alfa. Önceki 50 etap ve bunların kabul kanıtları bu geçişin gereksinim ve regresyon kaynağıdır. [Gereksinimler](REQUIREMENTS.md) · [M10 teslimi](M10_REPORT.md)
